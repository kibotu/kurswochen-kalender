## Fonts (self-hosted)

This site expects a locally hosted **Inter** font in this folder.

### Option A (recommended): Variable font

Put this file here:

- `InterVariable.woff2`
- `InterVariable-Italic.woff2` (optional)

### Option B: Static weights

Put these files here:

- `Inter-Regular.woff2` (400)
- `Inter-Medium.woff2` (500)
- `Inter-SemiBold.woff2` (600)
- `Inter-Bold.woff2` (700)

### Notes

- All paths are **relative** (`./fonts/...`) and there are **no external font URLs**.
- If these files are missing, the page falls back to system fonts.
- License: see `LICENSE-Inter.txt` (SIL Open Font License).
